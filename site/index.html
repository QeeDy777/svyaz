Подробности — когда понадобятся.

01

Сам найдёт подходящий альт

Последняя успешная стратегия проверяется первой. Затем — остальные. Для успеха нужны два прохода проверки API, Gateway и ответа голосового сервера Discord.

02

Обновит стратегии с GitHub

Загружает стабильные релизы Flowseal. Если обновление не прошло проверки, пробует предыдущий пакет. Новые версии самой «Связи» устанавливаются вручную.

03

Запустится после входа в Windows

Автозапуск включается при первом запуске. Приложение открывается в трее и начинает подбор. Отключить автозапуск можно в настройках.

04

Game Filter — под твою игру

TCP, UDP или оба протокола, свои порты и автоматическая загрузка IPSet. Фильтр работает с сетями из списка; результат нужно проверить в самой игре.

Первое подключение

Три простых шага.

  1. 1

    Распакуй архив

    Скачай ZIP из Releases и извлеки все файлы. Пять DLL должны оставаться рядом с Связь.exe.

  2. 2

    Открой «Связь»

    Подтверди запрос прав администратора. Приложение загрузит пакет zapret. Другой запущенный zapret сначала нужно остановить.

  3. 3

    Нажми «Подключить»

    Дождись подбора. Если программе нужен адрес голосового сервера, войди в голосовой канал Discord — дальше проверка продолжится сама.

О текущей сборке

EXE пока не подписан: Windows может показать SmartScreen. Запуск интерфейса, WinDivert и автозапуск ещё требуют проверки на Windows. Ответ голосового сервера не подтверждает передачу звука.

Полезно знать

Без сюрпризов.

Это VPN?

Нет. «Связь» управляет стратегиями zapret и запускает winws. Работа обхода зависит от провайдера, сети и выбранной стратегии.

Как включить Game Filter?

Отключись на главном экране, открой «Настройки → Игры · Game Filter», выбери режим и сохрани параметры. Подключись снова. По умолчанию фильтр выключен; исходный диапазон портов — 1024–65535.

Нужен пароль от Discord?

Нет. Приложение не входит в аккаунт и не читает токены. Адрес голосового сервера извлекается из локальных журналов Discord или вводится вручную.

Как полностью выключить приложение?

Крестик сворачивает окно в трей. Для полного завершения нажми правой кнопкой на значок «Связи» в трее и выбери «Выход (отключить обход)».

Что делать при ошибке запуска?

Проверь, что архив распакован полностью. При аварии окно ошибки показывает подробности и путь к startup-error.log. Описать проблему можно в Issues на GitHub; перед публикацией журнала проверь, что в нём нет личных данных.
