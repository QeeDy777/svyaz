# Страница «Связи»

Статическая страница GitHub Pages, без JavaScript, сборщика, внешних шрифтов
и аналитики. Исходники: `index.html`, `style.css`, `icon.png`.
Иконка — существующий PNG-кадр 256 × 256 из иконки приложения.
Изображение окна сделано HTML/CSS и явно отмечено как схема интерфейса.

Публикация: публичный репозиторий `QeeDy777/svyaz`, ветка `main`.
В Settings → Pages выбрать Source → GitHub Actions. Workflow `Publish website`
публикует только папку `site`, без исходников приложения и локальных файлов.
Адрес опубликованной страницы: https://qeedy777.github.io/svyaz/

Кнопки скачивания ведут в Releases этого репозитория. Опубликован релиз `v0.3.0`
с ZIP Windows x64 и файлом `.sha256`. Для новых версий приложить файлы из `dist`.
Имя архива начинается с `Svyaz`: GitHub удаляет кириллицу из имён вложений.
Имя EXE внутри архива остаётся «Связь.exe».
При выпуске новой версии обновлять номер в HTML вместе с `Directory.Build.props`.
Ссылка `releases/latest` продолжит вести на актуальный стабильный релиз.

Предпросмотр: `python3 -m http.server 8765 --directory site --bind 127.0.0.1`,
затем открыть http://127.0.0.1:8765/.

Проверено во встроенном браузере: ширины 320, 390, 768, 1024 и 1440 px,
отсутствие горизонтального переполнения, загрузка изображений, открытие FAQ
мышью и закрытие Enter, отсутствие ошибок консоли. Основные текстовые пары
имеют контраст не ниже 4.5:1. Проверены локальные ссылки, уникальность ID,
один H1 и соответствие версии проекта. Narrator и Safari на iPhone не проверены.
