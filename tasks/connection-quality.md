# Связь 0.10.0: качество ответа

Пользователь выбрал пункт 5: задержка и стабильность, выбор более устойчивого рабочего альта.

- Сохраняем типизированное время успешного ответа, без разбора строки журнала.
- При автоматическом подборе сравниваем до трёх кандидатов с тремя успешными проходами; после первого кандидата проверяем максимум ещё шесть стратегий. До первого рабочего — обычный перебор.
- Оценка: медиана максимального времени выбранных проверок в каждом проходе плюс диапазон этих времён. Меньше — лучше. Это короткая выборка, не игровой ping и не гарантия видео/звонка.
- После сравнения перезапускаем лучший кандидат и подтверждаем его двумя проверками. Если не прошёл — следующий из сравниваемых. Отмена всегда останавливает кандидата.
- Ручной выбор: только заданный альт, прежние два обязательных прохода.
- На главном экране и Telegram показываем до пяти последних результатов: отклик, разброс при двух и более измерениях, долю успешных проверок. При остановке/смене сети или стратегии выборка сбрасывается; ошибки учитываются, пропущенные проверки не участвуют.
- История альтов показывает их оценку. Фоновые проверки только обновляют показатели и существующее восстановление; ради уменьшения задержки исправное соединение не переключается.

Порядок: числовые измерения/оценка + Core-тесты → ограниченный подбор/повторная проверка + тесты отмены/отката → UI и Telegram → Windows CI/снимки/установщик/релиз.
Команды: `dotnet run --project tests/DiscordRoute.Checks`; `dotnet build tests/DiscordRoute.WindowsChecks`; Windows workflow для WPF, опубликованного EXE, установки и обновления.
Новых зависимостей нет. Порт/ключ/автозапуск и совместимость ZIP сохраняются. Реальная задержка и выбор стратегии в сети пользователя проверяются отдельно.
