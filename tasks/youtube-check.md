# Проверка YouTube

Пользователь выбрал совместный подбор: альт подходит только после двух проходов всех проверок Discord и YouTube.

- Проверять HTTPS `www.youtube.com/generate_204` и `redirector.googlevideo.com/generate_204` параллельно с Discord. Для каждой точки нужен именно HTTP 204; редиректы, 200 со страницей блокировки, ошибки TLS/DNS и тайм-аут не считаются успехом.
- Эти хосты входят в targets.txt Flowseal. Проверка подтверждает ответ сайта и перенаправителя Googlevideo, не воспроизведение ролика, скорость или доступность всех видеосерверов. Ограничение видно в интерфейсе и документации.
- Никаких учётных данных, cookies, системного прокси, отключения проверки сертификатов или запуска плеера. Тайм-аут 7 секунд; отмена общая с существующим подбором.
- Результат YouTube виден на главном экране, в истории каждого альта, журнале и безопасном отчёте (только nullable bool).
- Сохранённые альты также перепроверяются по новым условиям. Bootstrap для получения голосового адреса остаётся временным и не объявляет подключение проверенным.
- Покрыть отказ YouTube при доступном Discord, обязательный второй проход, отсутствие перенаправления, отмену, UI и экспорт. Проверить живые контрольные адреса и Windows CI, выпустить 0.7.1.

Источник хостов: https://github.com/Flowseal/zapret-discord-youtube/blob/main/utils/targets.txt
Ответы 204 обоих контрольных адресов проверены 16.11.2026. Это контроль HTTPS-соединения, а не поддерживаемый API воспроизведения.
