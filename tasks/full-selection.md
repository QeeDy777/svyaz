# Полный подбор 0.11.0

Отдельная кнопка на вкладке подключения. Перебирает все доступные альты пакета,
три успешных прохода выбранных Discord/YouTube для каждого рабочего кандидата,
оценка по существующему отклику/разбросу. Победитель подтверждается после запуска
двумя проходами; при неудаче следующий по оценке. Отмена останавливает подбор.

Быстрый подбор сохраняет ограничения. Ручной режим сессии сохраняет два прохода;
нажатие полного подбора явно переводит выбор интерфейса в автоматический.
Прогресс показывает i/N; ошибка запуска или проверки не прекращает весь перебор.
Настройки и сетевой профиль сохраняются существующим путём после подтверждения.
При смене сети не сохраняем профиль. Telegram-only не имеет кнопки альтов.

Проверки: победитель после третьего рабочего и после шести неудач, подтверждение
и запасной кандидат, отмена после границы быстрого режима, сохранение результата
через ConnectionSession, защита ручного режима, доступность кнопки и Windows UI.
