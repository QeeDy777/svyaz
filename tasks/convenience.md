# Связь 0.7: удобство использования

Пользователь одобрил все шесть предложенных функций. Главный экран остаётся узким (440×680), оформление — кремовый/зелёный, без новых зависимостей.

| Модуль | Результат | Зависимость |
|---|---|---|
| connection | Исправить подключение: автоматический повторный подбор; статусы, время подключения и последняя успешная проверка | существующие проверки Discord |
| networks | При подключении сначала проверяется альт, сохранённый для текущей сети Windows | connection |
| diagnostics | Сохранение JSON с версией, состоянием проверок и кодами ошибок | connection |
| tray | Исправление, проверка обновлений, текущая стратегия | connection |
| versions | История изменений, показ после установки, ручной откат на проверенную сохранённую версию | существующий updater |

Порядок: networks/connection → diagnostics/tray → versions → Windows UI/установщик → выпуск.

Условия приёмки:
- Восстановление игнорирует выбранный вручную альт, поддерживает отмену и существующий возврат прежнего процесса при неудаче.
- Идентификатор сети — хеш ID подключённых сетей NLM. Никаких SSID/IP в отчёте. При смене сети в процессе проверки результат ей не приписывается. Неизвестная сеть использует обычный подбор.
- Статус Discord различает проверено/процесс запущен/выключено; Telegram подтверждает только локальный прокси. Время сбрасывается после остановки.
- Отчёт формируется по разрешённым типизированным полям; не включает исходный журнал, настройки, адреса, имена сетей, ключи, имя пользователя, пути. Ошибки — HRESULT.
- История изменений доступна офлайн. После первого запуска новой версии раскрывается «Что нового», повторный запуск не навязывает её.
- Откат доступен только к сохранённым комплектным файлам с проверенным хешем и версией. Автообновление выключается, настройки сохраняются. Новые настройки хранятся отдельно в preferences.json, который старые версии не перезаписывают. Старые 0.5/0.6 должны запускаться без цикла перенаправления. Неуспешный запуск возвращает текущую версию.
- Установщик и автозапуск совместимы с откатом; удаление приложения очищает новые указатели обновления.

Проверки: dotnet run --project tests/DiscordRoute.Checks; dotnet build src/DiscordRoute.App --disable-build-servers; Windows CI: WPF screenshots, self-update/rollback, real Telegram binary, installer lifecycle.

Нельзя: менять системную сеть/антивирус, отправлять отчёт автоматически, удалять настройки при откате. Ручные ограничения: живой Discord/сеть провайдера проверяются на Windows пользователя.
