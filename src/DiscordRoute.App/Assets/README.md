# Иконка «Связи»

В `icon-source.png` хранится оригинальный логотип из веб-панели ASF Control (640 × 640). «Связь» показывает его в шапке окна.

В `app.ico` входят семь PNG-кадров RGBA размером 16, 24, 32, 48, 64, 128 и 256 пикселей для EXE, окна, трея и установщика. Сайт использует тот же кадр 256 × 256.
