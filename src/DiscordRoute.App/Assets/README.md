# Иконка «Связи»

Янтарная плитка с графитовыми звеньями создана встроенным ImageGen. В поставляемом исходнике `icon-source.png` (512 × 512) под знаком лежит янтарная подложка, чтобы он одинаково читался на светлом и тёмном фоне. Внешние углы прозрачны.

`app.ico` содержит семь PNG-кадров RGBA размером 16, 24, 32, 48, 64, 128 и 256 пикселей. Этот файл используется для EXE, окна, трея и установщика. В шапке WPF используется исходный PNG, на сайте — кадр 256 × 256.

Промпт ImageGen:

> Create a single square Windows desktop app icon for Связь. Centered bold simple glyph of two broad interlocking diagonal open links, reading as one optically balanced connection mark. Near-black graphite #1c1f22 glyph carved across a warm apricot amber #ffb770 rounded-square tile. One warm accent, flat saturated color fields, crisp geometric optical spacing and generous negative space at the crossing; distinctive silhouette legible at 16 px. Tile fills nearly all the canvas. Face on, no extrusions or perspective, no outer shadow, no text, no lettering, no additional objects. True transparent corners outside the amber tile. Output one icon only.
