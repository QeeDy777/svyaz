# Связь 0.2.1

По запросу пользователя: минимализм, вертикальный прямоугольник, фиксированный
размер и русское название. «Связь» заменяет пользовательское имя DiscordRoute;
технические пути данных, mutex и задача автозапуска сохраняются для совместимости.

Окно 440 × 680 DIP, ResizeMode=CanMinimize: нет ручного изменения размера и
разворачивания. На рабочем столе меньшей высоты окно ограничивается рабочей областью.
Масштаб Windows DPI сохраняется; Viewbox или уменьшение всего интерфейса не используются.

Композиция: название и версия вверху, три компактные вкладки. На главной — короткий
статус, одна круглая кнопка, три текстовых индикатора и закрытая история проверок.
Кнопка подключает в покое, отменяет во время операции, отключает при работающем
процессе. Один и тот же Button сохраняет клавиатурный фокус при смене команды.
Скрытая история содержит полный текст результатов без узких столбцов таблицы.
Настройки разделены линиями, журнал занимает доступную высоту.

Системная Fluent-тема, спокойный фон, один системный цвет акцента, Segoe UI Variable.
Статусы имеют текст, а не только цвет. Кнопка — настоящий WPF Button с видимым
клавиатурным фокусом и реакцией на нажатие. При отключении системной анимации
индикатор статичен. Все страницы доступны с клавиатуры и прокручиваются.

Иконка: белые звенья на бирюзовом фоне. Assets/app.ico содержит семь размеров и
встроен в Windows PE, WPF-ресурсы и трей. Исходный PNG и описание генерации сохранены
в Assets. Новых библиотек нет.

Компиляция и проверки состояния не заменяют просмотр на Windows. Реальный рендеринг,
DPI, Narrator, смена темы, Проводник и трей остаются в Windows smoke test.
